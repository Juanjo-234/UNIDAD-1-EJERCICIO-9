# UNIDAD-1-EJERCICIO-9
Resolución del ejercicio N°9 de la unidad 1 de programación 2.
Este programa gestiona el almacenamiento de un plan de alojamiento web.
Registra el espacio consumido por los archivos subidos y bloqueando la carga si se intenta superar la capacidad máxima permitida del servidor.
Al final muestra en consola un informe de cuanto es el espacio ocupado y cuanto es el almacenamiento libre.
En caso de que un archivo supere supere la capacidad máxima, se emitirá un mensaje donde especifica que superó la capacidad permitida y no fue subido.
